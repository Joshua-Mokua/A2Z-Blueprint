### CascadeManager additions

```python
# New methods on CascadeManager:
get_buffer_cap(kpi: str) → float           # returns max % allowed
set_buffer_cap(kpi: str, max_pct: float)    # MD sets
get_my_stretch_target(staff_code, kpi, period) → float
                                            # returns most-local stretched target
get_my_base_target(staff_code, kpi, period) → float
                                            # returns base target (for secondary display)
```

### Validation rule

When manager sets allocation with `buffer_pct=B` for KPI `K`:
- Lookup `cap = get_buffer_cap(K)` (default 15%)
- Assert `B <= cap`, else reject with clear error
